# DEVKiTZ Main Dashboard

DEVKiTZ Main Dashboard — 132+ Module, Glassmorphism Design, DkZ Design System v2.

## Features

- 132+ dashboard modules for agents, content, analytics, and design
- Glassmorphism UI with dark mode and DkZ Design System v2
- Shared scripts system (dkz-theme.css, dkz-navbar.js, dkz-debug.js, dkz-guide.js)
- Offline-first with localStorage persistence
- XSS-protected, responsive mobile-first layout

## Tech Stack

Vanilla HTML5 / CSS3 / JavaScript ES6+ · Zero frameworks · GitHub Pages

## Quick Start

```bash
git clone https://github.com/D-VKITZ/D-VKITZ.github.io.git
cd D-VKITZ.github.io
# Open index.html in browser or serve locally
npx serve .
```
